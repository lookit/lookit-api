This table shows total number of tallied and untallied responses for this study (all preview responses are ignored). {% if not is_external %}The total number of tallied responses includes those with either approved or pending consent judgments. {% endif %}The tallied response count is used to determine if your study has met/exceeded the study's response limit.

Because this is an {% if is_external %}external{% else %}internal{% endif %} study, a response is automatically categorized as tallied when:

  • It is not a preview
  • The participating child is eligible
    • {% if not is_external %}
  • The family completed a consent frame
  • The consent has not been rejected
  • The participant completed the study
    • {% endif %}

{% if not is_external %}

The values in parentheses show the number of responses out of the total that are still pending consent judgment. These are categorized with the assumption that their consents will be approved. If a tallied response with pending consent turns out not have valid consent, then it will become untallied when you reject the consent, which will decrease the study's tallied response count. Please make sure that you handle any pending consents to keep your tallied count accurate. The remaining responses have approved consents and are available now to view and download.

{% endif %}

You can override the automatic tallied/untallied categorization on the Individual Responses page. {% if is_external %} Responses are categorized with the assumption that, when a family clicks the button to participate or schedule a time to participate, they will complete the study. You may need to change tallied responses to untallied when a family clicks this button but does not actaully complete the experiment or schedule a synchronous session. {% else %} You may find that some untallied responses should be changed to tallied, for instance, because the participant finished most of the study but missed the last trial, so their session was marked as incomplete. However, changing a response from tallied to untallied should be relatively rare. Tallied responses do not need to be analyzeable in your research, for instance, because the child was fussy or inattentive. {% endif %} Responses should be tallied if they meet the criteria above and the family participated in good faith.
